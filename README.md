# 🗳️ Election Management System

An interactive console-based **Election Management System** developed in **C Programming** as our **1st Semester CSE project**.  
This project was designed with a modern terminal-style UI, animations, and multiple election management features.

---

## 📌 Project Overview

The Election Management System is a complete voting simulation project that allows:

- Secure admin control
- Voter registration
- Vote casting
- Live vote counting
- Election result analysis
- Statistics dashboard

The project focuses on both **functionality** and **visual presentation** using an attractive ASCII-based UI.

---

# ✨ Features

## 🔐 Admin Panel (Password Protected)

Only authorized admins can access these controls:

- Voter area management
- Voting center assignment
- Voter limit setup
- Political party symbol setup
- Election configuration controls
